# Smart Health Appointment & Queue System

## 1. Project Overview

Smart Health Queue is a web-based healthcare appointment and queue
management system.

The system helps patients book appointments, receive queue numbers,
and monitor their position in the queue.

It also helps doctors manage appointments and allows administrators
to manage the healthcare facility.

---

## 2. Problem Statement

Patients can spend a long time waiting in healthcare facilities.

Clinics may also have difficulty managing appointments, schedules,
and waiting queues efficiently.

The goal of this project is to create a digital system that makes
appointments and queues easier to manage.

---

## 3. Project Objectives

The system should:

- Allow patients to create accounts.
- Allow patients to book appointments.
- Generate queue numbers.
- Allow patients to view their queue status.
- Allow doctors to manage their appointments.
- Allow doctors to manage the patient queue.
- Allow administrators to manage doctors and appointments.
- Reduce unnecessary waiting time.
- Provide a simple and user-friendly interface.

---

## 4. User Roles

### 4.1 Patient

Patients can:

- Register an account.
- Log in.
- View doctors.
- View available appointments.
- Book an appointment.
- Cancel an appointment.
- Receive a queue number.
- View their queue position.
- View appointment history.

### 4.2 Doctor

Doctors can:

- Log in.
- View their daily appointments.
- View the patient queue.
- Call the next patient.
- Complete an appointment.
- Mark a patient as absent.
- View their schedule.

### 4.3 Administrator

Administrators can:

- Log in.
- Add doctors.
- Edit doctor information.
- Remove doctors.
- Manage patients.
- Manage departments.
- Create doctor schedules.
- Manage appointments.
- Monitor queues.
- View system statistics.

---
